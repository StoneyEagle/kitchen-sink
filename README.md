# Foghorn Blog Journal — Template

This is a reference template used by `foghorn init blog-journal`. Users copy it into their own repo and customise.

## Local development

```
npm install
npm run dev
```

## Build

```
npm run build    # runs sync.mjs, then astro build
```

## Deploy

The template works with any static host. Default deployment target is GitHub Pages; see `foghorn.config.json` `deployment` field.

## Editing

- Entries live under `entries/journal/<date>-<nnn>-<slug>/entry.md`.
- Never edit `src/foghorn/` — it's regenerated by `sync.mjs`.
- Everything else is yours to modify.
