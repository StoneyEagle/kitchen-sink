# Callouts

<!-- block: 01KPMRMZDVTMND4296D70083XF -->
Every callout variant, each with a title, a short body, and at least one inline mark so renderers get exercised on composition.

<!-- block: 01KPMRMZDVAH8SGXGR8WEAHMAR -->
```callout:info
title: Info
body: |
  This is an **info** callout — neutral, informational. Use it when the content is background or reference.
```

<!-- block: 01KPMRMZDVJ69JB0T3X6GBCPRT -->
```callout:tip
title: Pro tip
body: |
  Use *tip* callouts sparingly. The signal collapses if every paragraph is a tip.
```

<!-- block: 01KPMRMZDVWGPXVWD3Y99ZFVY3 -->
```callout:note
title: Author's note
body: |
  A `note` is the softest variant. It's what you reach for when there's nothing scarier than "you might not have noticed this".
```

<!-- block: 01KPMRMZDVEYCM3TGPEZ9FKTK7 -->
```callout:success
title: Shipped
body: |
  `success` means a thing worked. Use it in tutorials after a step that confirms progress.
```

<!-- block: 01KPMRMZDVJPFMT62NQFMM7FDA -->
```callout:warn
title: Heads up
body: |
  Warnings flag behaviour that's likely to surprise. Not a breakage — just "watch out".
```

<!-- block: 01KPMRMZDVA8Z5WNRWT62V07X1 -->
```callout:danger
title: Do not
body: |
  Danger means don't. When you see one of these, the instruction is a **hard stop** — there's something that will break if you ignore it.
```

<!-- block: 01KPMRMZDVZH97KZKRK99RG9CA -->
```callout:quote
title: From the owner
body: |
  The `quote` callout wraps a citation in the same chrome as the other variants so it visually lines up with the rest of a docs page.
```
